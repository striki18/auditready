# Cline.md – Windows Development Rules

**Command Environment Rules**

This project runs on **Windows PowerShell**. All terminal commands must be compatible with PowerShell and use the Windows‑specific executables.

## Disallowed Commands / Syntax

Never generate or use the following (they are Unix‑style or aliases that do not exist in PowerShell):

- `curl` (use `curl.exe` instead)
- `bash` commands
- Linux shell utilities such as `head`, `grep`, `cat`, `rm`, `cp`, `mv`
- `ls` (use `Get-ChildItem`)
- Unquoted URLs containing `&` (PowerShell treats `&` as a command separator)

## Required Commands / Syntax

### HTTP Requests

Use the full executable name:

```powershell
curl.exe -i "http://localhost:3000/api/test"
```

When the URL contains query parameters, **always wrap the URL in double quotes** to prevent PowerShell from interpreting `&` as an operator:

```powershell
curl.exe -i "http://localhost:3000/api/auth/callback?code=abc&state=xyz"
```

### File Inspection & Modification

Use PowerShell cmdlets:

- `Get-Content` (instead of `cat`)
- `Set-Content` / `Add-Content`
- `Get-ChildItem` (instead of `ls`)
- `Copy-Item`, `Move-Item`, `Remove-Item` (instead of `cp`, `mv`, `rm`)

### Example

```powershell
# Read a file
Get-Content .\README.md

# List files in a directory
Get-ChildItem -Path .\src
```

These rules are **global** and apply to every future task in this repository.
